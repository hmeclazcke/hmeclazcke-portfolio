# hmeclazcke-portfolio

An interactive technical portfolio with an established static frontend foundation.

## Frontend development

Prerequisite: Node.js 24 LTS (npm is included).

Run all frontend commands from `frontend/`:

```powershell
npm install
npm run dev
```

The Phase 1 frontend runs locally without a project backend.

Validate frontend changes with:

```powershell
npm run format:check
npm run lint
npm run typecheck
npm run test:run
npm run build
```

Detailed product, architecture, quality, and development-state documentation is maintained in [docs/](docs/).
